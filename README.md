# agents-common

Shared Python library for the agents trigger services (part of the agents-webhook-component
project): database access, settings, HTTP helpers and test fixtures, so each service stays small.

Install:

    agents-common @ git+https://github.com/szymonrychu/agents-common@v0.1.0

Modules (filled in per module by later tasks):

- `agents_common` - package root, `__version__`.
